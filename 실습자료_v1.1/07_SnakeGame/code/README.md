# 07_SnakeGame 코드 폴더

스네이크 게임 프로젝트의 단계별 코드입니다.

## 폴더 구조

```
code/
├── step1-basic/       # 클립 2: 기본 게임
├── step2-difficulty/  # 클립 3: 난이도/일시정지/레벨업
├── _archive/          # 기존 완성 코드 백업
└── README.md
```

## 각 단계별 내용

### step1-basic (클립 2: 기본 게임)
- Canvas로 게임판 그리기
- 뱀 이동 로직 (방향키)
- 음식 생성 및 섭취
- 벽/자기몸 충돌 감지
- 점수 및 최고점수 (LocalStorage)

### step2-difficulty (클립 3: 난이도/일시정지/레벨업)
- 난이도 선택 (쉬움/보통/어려움/매우 어려움)
- 레벨 시스템 (50점마다 레벨업, 속도 증가)
- 일시정지 기능
- 개선된 UI 스타일

## 실행 방법

각 폴더에서:
```bash
python3 -m http.server 8000
```
http://localhost:8000 접속

- **PC**: 방향키 (↑ ↓ ← →)
